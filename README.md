## Чем я занимаюсь

- Разрабатываю backend на Python: Django, FastAPI, REST API, авторизация, роли, CRUD, работа с БД.
- Проектирую локальную инфраструктуру: Docker, Docker Compose, nginx, PostgreSQL, Redis.
